# Go code

Refines `~/.claude/rule-details/go/wrapping-errors.md` and `~/.claude/rule-details/coding-style.md`.

- **GO1** `client.gen.go` is generated by oapi-codegen and never edited by hand. To change it, change `config.yaml` or a patch in `internal/cmd/patchspec`, then run `make generate` and commit the result.
- **GO2** A spec shape oapi-codegen cannot read is fixed in `internal/cmd/patchspec/main.go`, which works on the YAML tree. Each patch says in a comment what is wrong upstream and what it changes. The downloaded spec under `api/` is gitignored and never committed.
- **GO3** Hand-written Go wraps errors with `github.com/psyb0t/ctxerrors`. The `together` package never logs and never prints; `patchspec` logs with `log/slog`.
- **GO4** The exported API is whatever oapi-codegen generates. A regeneration that renames or removes an exported name is a breaking change (see `releases.md`).
- **GO5** `make lint` passes with zero issues. Hand-written lines are at most 80 columns, the `.golangci.yml` limit; split calls one argument per line rather than adding `//nolint`.
- **GO6** Shell scripts in `scripts/` pass shellcheck and shfmt, which `make lint` runs.
